# 🏨 EDA on Hotel Booking Dataset

This project focuses on **Exploratory Data Analysis (EDA)** of a **Hotel Booking Dataset** to uncover hidden patterns, trends, and insights that impact hotel bookings. Using Python's powerful data analysis libraries, this project explores booking behaviors, cancellations, seasonal trends, and other key factors affecting hotel performance.

## 📊 Dataset Overview

The dataset contains information about hotel bookings, including details such as:

- Booking dates  
- Hotel types (City Hotel or Resort Hotel)  
- Guest demographics  
- Stay durations  
- Cancellation status  
- Pricing and special requests  

📁 **Source:** [Hotel Booking Dataset on Kaggle](https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand)

---

## 🚀 Key Objectives

- Perform data cleaning and preprocessing  
- Analyze booking trends across hotel types  
- Identify factors leading to cancellations  
- Study seasonal booking patterns  
- Visualize insights using graphs and charts  

---

## 🛠️ Tools & Technologies

- **Python** 🐍  
- **Pandas** for data manipulation  
- **NumPy** for numerical operations  
- **Matplotlib** & **Seaborn** for data visualization  
- **Jupyter Notebook** for interactive analysis

## 📌 Insights Discovered

- 📅 **Seasonal Trends:** Higher bookings during summer holidays  
- 💸 **Cancellation Patterns:** Certain room types have higher cancellation rates  
- 🌍 **Guest Origins:** Majority of bookings from specific countries  
- 💰 **Revenue Factors:** Impact of special requests and meal types on pricing

## 🧮 How to Run the Project

1. **Clone the repository:**

   ```bash
   git clone https://github.com/muhammadadilnaeem/Data-Science-Materials.git
   cd Data-Science-Materials/Codanics/projects/2. EDA On Hotel Booking Dataset
   ```

2. **Set up a virtual environment (optional but recommended):**


   ```bash
   pip install -r requirements.txt
   ```

4. **Launch Jupyter Notebook:**

   ```bash
   jupyter notebook
   ```
